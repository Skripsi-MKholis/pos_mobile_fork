## 2024-05-20 - [Optimize List Filtering .where()]
**Learning:** In Dart/Flutter, operations inside a list `.where()` filter are executed O(N) times. Hoisting invariant operations (like converting a search query string to lowercase) outside the filter loop significantly reduces redundant string allocations and computations. Furthermore, ordering the inner conditions to perform cheap checks (like comparing IDs) before expensive checks (like string `.contains()`) acts as a fast-path short-circuit, improving overall CPU efficiency during frequent events like typing in a search bar.
**Action:** Always inspect list filtering and sorting functions to hoist constants and order conditions from cheapest to most expensive.
