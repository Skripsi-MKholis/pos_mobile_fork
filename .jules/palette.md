## 2026-05-25 - [Tooltip Accessibility for Icon Buttons]
**Learning:** Icon-only buttons (like delete, flash, or close) lack inherent context for screen readers and new users, leading to poor accessibility and discoverability.
**Action:** Always wrap icon-only buttons (e.g., `IconButton`, `ShadIconButton.outline`) in a `Tooltip` widget with localized Indonesian UI copy (e.g., 'Hapus Voucher', 'Tutup') to enhance accessibility and user understanding.
